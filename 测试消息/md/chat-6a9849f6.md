## 3. Kotlin annotation target 变化：数量最多，但实际上是一类问题

日志里大量重复的是这一组：

> `This annotation is currently applied to the value parameter only, but in the future it will also be applied to field.`
> `- To opt in to applying to both value parameter and field, add '-Xannotation-default-target=param-property' to your compiler arguments.`
> `- To keep applying to the value parameter only, use the '@param:' annotation target.` file

类似 warning 分布在：

- `MainViewModel`
- `ConfigInitializer`
- `ExploreRepository`
- `SearchRepository`
- `UserProfileRepository`
- `OKSignRepository`
- `HabitSettings`
- `FollowUser`
- 大量 ViewModel / UI State / Compose 类等。file file file

这不是几十个独立 bug，而是**Kotlin annotation 默认 use-site target 行为正在改变**。

比如类似：

```kotlin
data class Foo(
    @SomeAnnotation
    val value: String
)
```

过去它可能只落在 constructor parameter：

```kotlin
@param:SomeAnnotation
```

以后默认行为可能也涉及 property / field。

所以编译器要求你明确选择语义。

如果你本来就是想标注构造参数，应改成：

```kotlin
@param:SomeAnnotation
val value: String
```

如果新的 param + property 行为正是项目想要的，可以在 Kotlin compiler args 中加入：

```text
-Xannotation-default-target=param-property
```

**不建议单纯为了消 warning 就全局加参数。** 最好先确认这里到底是哪种 annotation，尤其如果涉及：

- Hilt / Inject
- Serialization
- Room
- Compose
- 自定义注解

因为 use-site target 有实际语义区别。

如果先不谈政治立场，单看“怎么想问题”，《毛选》有几个很突出的特点：第一，特别强调从具体情况出发，而不是先套结论，比如常说的“调查研究”“具体问题具体分析”；第二，很重视主要矛盾、力量对比和阶段变化，也就是先判断眼下最关键的问题是什么；第三，强调实践和反馈，很多文章不是纯理论推演，而是围绕“现在处在什么局面、有哪些资源、该怎么行动”展开；第四，很擅长把复杂问题压缩成相对清晰的结构，所以读起来常有很强的“方法论感”。

不过也要注意，《毛选》不是一本脱离历史环境的通用管理学教材。它的很多判断都服务于当时的战争、革命和政治组织环境，其中一些概念如果直接搬到今天的职场、商业或日常生活里，很容易过度类比。另一方面，它又确实有不少分析框架具有跨情境的启发性，所以比较好的读法是：**把“方法”与“历史结论”分开看。**

《毛泽东选集》常见前四卷，核心不是单纯讲政治结论，而是展示一种**分析现实、判断矛盾、制定策略**的方法。

比较适合入门的几篇：
- 《反对本本主义》：强调调查和实际情况；
- 《实践论》：讨论认识如何从实践中产生、再回到实践；
- 《矛盾论》：讨论主要矛盾、矛盾主要方面；
- 《论持久战》：很典型的战略分析文本。

读的时候最好把**历史背景、政治立场和可迁移的方法论分开看**。它最有价值的地方，往往不只是“结论是什么”，而是“这个结论是怎么一步步推出来的”。
